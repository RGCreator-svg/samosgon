ДЕРЕВО УМЕНИЙ «САМОГОНЩИК: ТРИ КИТА» — полное описание
(синхронизировано с src/domain/skillTree.ts)
================================================================

СТРУКТУРА
  Всего узлов: 29 (1 стартовый + 28 умений в 7 ветках).
  Формат узла: id | название | стоимость (очки) | требуемые узлы | эффект.
  Связи «требует» заданы полем requires, плюс 5 нестандартных рёбер
  EXTRA_EDGES (для отрисовки линий на схеме, на изучение не влияют).
  Три кейстоуна имеют конфликты (поле conflicts).

КООРДИНАТЫ СХЕМЫ
  Старт — центр (800, 520). Ветки расходятся:
  вверх (дистилляция), влево-вниз (ректификация), вправо-вниз (коммерция),
  влево-вверх (огород), влево (травы), вправо-вверх (сад), вправо (пасека).
  Цвета веток: start #cfa060, dist #e0a34a, rect #5aa7e0, comm #e0c04a,
  farm #7ec850, herbs #a8d060, orchard #e07070, apiary #f0c040.

----------------------------------------------------------------

НЕСТАНДАРТНЫЕ РЁБРА (EXTRA_EDGES) — только для схемы,
условием изучения НЕ являются:
  d4 — o3   (секрет Тыка соединяется с «Редкими сортами»)
  r2 — h1   (тарельчатая колонна соединяется с «Травами и специями»)
  c1 — o1   (торг соединяется с «Фруктовым садом»)
  a2 — c2   (дымарь соединяется с «Связями»)
  f2 — h1   (теплица соединяется с «Травами и специями»)

----------------------------------------------------------------
КОНФЛИКТЫ КЕЙСТОУНОВ (взаимоисключающие узлы):
  d3 «Дистиллят с душой»  <->  r3 «Абсолют»
  d3 «Дистиллят с душой»  <->  o3 «Редкие сорта»
  r3 и o3 между собой НЕ конфликтуют.
  Смысл развилки: либо ароматный путь (дистилляты с характером,
  редкие вкусы), либо чистый путь (ректификат 96,6).

----------------------------------------------------------------
СВОДКА ЭФФЕКТОВ ПО ВЕТКАМ (если выучить ветку целиком):
  dist: выход +20%, аромат +45%, цена +10%
  rect: чистота +55%, головы смягчены на 3%, цена ректификата +20%
  comm: цена +55%, стабильность рынка +30%
  farm: овощи +8 кг/день
  herbs: травы +4 кг/день + рецепт настойки
  orchard: фрукты +4 кг/день + редкие вкусы + рецепт сидра
  apiary: мёд +4 кг/день + рецепт медовухи

----------------------------------------------------------------
СВЯЗЬ С ИНФОГРАФИКОЙ «ТРИ КИТА»:
  Этап 1 «Приготовление браги» — доступен с начала; усиливается
    ветками сырья: farm, orchard, apiary, herbs.
  Этап 2 «Разделение» — усиливается веткой dist (выход и аромат).
  Этап 3 «Улучшение» — усиливается ветками rect (ректификат) и
    herbs (настойка); коммерция (comm) ускоряет окупаемость любого пути.

----------------------------------------------------------------
МЕХАНИКА ИЗУЧЕНИЯ (canLearn):
  Узел доступен, если: он ещё не выучен; все узлы из requires
  выучены; ни один из узлов в conflicts не выучен.
  Стоимость узла — очки умений, которые игрок тратит при изучении.
