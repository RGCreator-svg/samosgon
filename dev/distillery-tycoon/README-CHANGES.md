# Самогонщик: Три кита — сборка v0.7 (React Flow + фиксы движка)

Дата сборки: 17.11.2026. Это полная копия проекта с применёнными правками.

## Что исправлено (баги, найденные при ревизии)

1. **Рынок всегда был пуст.** В Market.tsx и ThreeWhales.tsx `PRODUCTS` (массив) обходили через
   `Object.keys()` — получались индексы «0…9», а не id товаров. Теперь обход по массиву,
   а в catalog.ts добавлена карта `PRODUCTS_BY_ID` для поиска по id.
2. **Склад показывал сырые id** вместо названий («raw-sugar» вместо «Сырец сахарный») —
   та же причина, исправлено через `PRODUCTS_BY_ID`.
3. **Разделы магазина не открывались.** Ключи секций в Shop.tsx (`still`, `brewery`, `provisions`,
   `storage`) не совпадали с `SHOP.section` (`distill`, `brew`, `provision`, `build`) —
   были видны только детали колонны. Исправлено.
4. **Склад никогда не расширялся.** `capacity()` читала `capBonus/capMult`, а в SHOP поля
   называются `storageBonus/storageMultiplier`. Исправлено и в `capacity()`, и в `buy()`.
5. **Несовпадения id техники** в useGame: `dimka2` → `dimka-2`, `pure-spirit-app` → `apparatus-pure`,
   `fermenter-plastic/steel` → `fermenter-basic/seal/pro`, `tsarga-steel` → `tsarga-n`,
   `dephlegm-basic` → `dephl-simple`, `takeoff-basic` → `node-simple`, `packing-selivanenko` → `packing-sel`.
   Семейство cooler убрано (таких товаров в магазине нет) — колонна состоит из 4 узлов, как и задумано.
6. **Товары рынка не сходились со складом.** Ректификация писала `rect-spirit`, бочка — `aged-spirit`,
   а рынок продавал `rectified`/`aged`. Приведено к id из PRODUCTS.
7. **Настойка была невозможна.** Рецепт требовал `samogon`, который нигде не производится.
   Теперь рецепт принимает `any-raw` (любой сырец: сахарный/фруктовый/овощной) — движок суммирует
   и списывает подходящие литры.
8. **Дубли в Production.tsx**: второй заголовок и вторая лента «Три кита» убраны.
9. **Дерево умений переключено на React Flow** (`SkillTreeRF`), App.tsx обновлён.
   Старый SVG-компонент `SkillTree.tsx` оставлен в проекте как запасной, но не рендерится.
   `SkillTreeBST.tsx` (beautiful-skill-tree) больше не нужен — можно удалить вместе с пакетом.

## Новые ветки подключены к движку

| Узел | Эффект в игре |
|---|---|
| bk1–bk4 «Бочка и выдержка» | рейтинг выдержки и цена выдержанного в `priceOf('aged')`; конфликт с r4 действует |
| soc1 «Репутация» | события реже, плохие исходы мягче (−30% за уровень) |
| soc2 «Городской совет» | провизия в магазине −10% |
| soc3 «Контракт с трактиром» | редкие сорта (при изученном o3) +30% к цене |
| soc4 «Постоянный контракт» | каждые 7 дней премия 1500 руб. × (1 + цена) |
| hnd1–hnd4 «Рука мастера» | шире «хорошая» зона отсечения, награда репутацией ×1,15, шанс идеального отсечения 5%, подсказка в мини-игре |
| fm1 «Гончарная мастерская» | брожение −1 день |
| th1 «Травяной дистиллят» | настойка +20% к цене |
| fh1 «Фруктовая медовуха» | медовуха +25% к цене |
| dz1 «Дегустационный зал» | скрытый узел; раз в неделю сырец фруктовый ×1,5 |
| book «Книга Тыка» | одноразовый сброс ветки (`resetBranch`), кнопка в шапке дерева |
| aroma / purity | аромат поднимает цену сырца (×0,4 за уровень), чистота — выход и цену ректификата |

## Запуск

```
npm install        # подтянет @xyflow/react
npm run dev
```

Если сейв от v0.6 вели себя странно — сбрось localStorage (ключ `samosgon-v6`).
