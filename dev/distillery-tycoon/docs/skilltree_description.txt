ОПИСАНИЕ ДЕРЕВА УМЕНИЙ (v2)
===========================

СТАРТ
  start  Заводской двор (0) — без требований. Корень дерева.

ДИСТИЛЛЯЦИЯ (dist)
  d1 Соложение (1)                 +5% выход.                req: start
  d2 Двойная дробная перегонка (2) +10% выход, +5% аромат.  req: d1
  d3 Дистиллят с душой (4)         +25% аромат, +10% цена.   req: d2  КОНФЛИКТ: r3, o3
  d4 Секрет дядюшки Тыка (6)       +15% аромат, +5% выход.   req: d3

РЕКТИФИКАЦИЯ (rect)
  r1 Узлы отбора (1)               +10% чистота.             req: start
  r2 Тарельчатая колонна (2)       +15% чистота.             req: r1
  r3 Абсолют (4)                   +10% чистота, головы −3%. req: r2  КОНФЛИКТ: d3
  r4 96,6 без вопросов (6)         +20% чистота и цена.      req: r3  КОНФЛИКТ: bk4

КОММЕРЦИЯ (comm)
  c1 Торг (1)                      +10% цена.                req: start
  c2 Связи (2)                     +10% цена, события.       req: c1
  c3 Рука рынка (4)                +15% цена, стабильность.  req: c2
  c4 Сеть таверн (6)               +20% цена.                req: c3 + ЛЮБОЙ из d3, r3, o3, bk4

ОГОРОД (farm)
  f1 Огородничество (1)            +1 кг овощей.             req: start
  f2 Теплица (2)                   +2 кг овощей.             req: f1, h1
  f3 Компост и севооборот (4)      +2 кг овощей.             req: f2
  f4 Большая грядка (6)            +3 кг овощей.             req: f3
  fm1 Гончарная мастерская (3)     брожение −1 день.         req: f1 (кросс-узел)

СПЕЦИИ И ТРАВЫ (herbs)
  h1 Травы и специи (1)            +1 кг трав.               req: start
  h2 Сушка и хранение (2)          +1 кг трав.               req: h1
  h3 Настойки и настои (4)         открывает рецепт.         req: h2
  h4 Букет специй (6)              +2 кг трав.               req: h3
  th1 Травяной дистиллят (3)       +20% цена настоек.        req: h3, d2 (кросс-узел)

ФРУКТОВЫЙ САД (orchard)
  o1 Фруктовый сад (1)             +1 кг фруктов.            req: start
  o2 Сидр и наливки (2)            открывает сидр.           req: o1
  o3 Редкие сорта (4)              +1 кг, редкие вкусы.      req: o2  КОНФЛИКТ: d3
  o4 Ягодная аллея (6)             +2 кг фруктов.            req: o3

ПАСЕКА (apiary)
  a1 Пасека и пчёлы (1)            +1 кг мёда.               req: start
  a2 Дымарь и уход (2)             +1 кг мёда.               req: a1
  a3 Рецепт медовухи (4)           открывает медовуху.       req: a2, d1
  a4 Липовый мёд (6)               +2 кг мёда.               req: a3
  fh1 Фруктовая медовуха (4)       +25% цена медовухи.       req: a3, o2 (кросс-узел)

БОЧКА И ВЫДЕРЖКА (oak)
  bk1 Первая бочка (1)             +1 рейтинг выдержки.      req: start
  bk2 Дубовые клёпки (2)           +5% цена выдержки.        req: bk1
  bk3 Лимузенский дуб (4)          +10% цена выдержки.       req: bk2
  bk4 Тыковка (6)                  +40% цена выдержанного.   req: bk3  КОНФЛИКТ: r4

ГОРОД И СОБЫТИЯ (soc)
  soc1 Репутация на рынке (1)      реже плохие события.      req: start
  soc2 Городской совет (2)         провизия −10%.            req: soc1
  soc3 Контракт с трактиром (4)    редкие ×1,3.              req: soc2
  soc4 Постоянный контракт (6)     еженедельная премия.      req: soc3

РУКА МАСТЕРА (hands)
  hnd1 Чувство капли (1)           зона мини-игры +10%.      req: start
  hnd2 Тонкая настройка (2)        награда +15%.             req: hnd1
  hnd3 Мастер голов (4)            идеальное отсечение +5%.  req: hnd2
  hnd4 Интуиция дистиллятора (6)   авто-подсказка.           req: hnd3

КНИГА ТЫКА
  book Книга дядюшки Тыка (5)      один сброс ветки.         req: start

СКРЫТЫЙ УЗЕЛ
  dz1 Дегустационный зал (5)       редкие ×1,5 раз в неделю. req: c2, d3
      Раскрывается, когда изучены «Связи» и «Дистиллят с душой».

КОНФЛИКТЫ (красный пунктир на схеме)
  d3 ↔ r3,  d3 ↔ o3,  r4 ↔ bk4

EXTRA_EDGES (только линии отрисовки, логику не меняют)
  d4→o3, r2→h1, c1→o1, a2→c2, f2→h1

СВОДКА ПО ВЕТКАМ (полное прохождение)
  dist:  +20% выход, +45% аромат, +10% цена (13 очков)
  rect:  +55% чистота, +20% цена, головы −3% (13 очков)
  comm:  +55% цена, стабильность рынка (13 очков)
  farm:  +8 кг овощей/день (13 очков)
  herbs: +4 кг трав/день, рецепт настойки (13 очков)
  orchard: +4 кг фруктов/день, сидр, редкие вкусы (13 очков)
  apiary:  +4 кг мёда/день, медовуха (13 очков)
  oak:   +1 выдержка, +55% цена выдержанного (13 очков)
  soc:   премия, скидки, стабильность (13 очков)
  hands: +10% зона, +15% награда, +5% идеал, подсказка (13 очков)
