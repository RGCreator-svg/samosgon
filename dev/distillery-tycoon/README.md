# Самогонщик: Три кита — v0.6

Экономическая симуляция домашнего винокурения с деревом умений в стиле Path of Exile,
складом, онлайн-магазином редких деталей, пивоварней, пасекой и медовухой.

## Запуск
```
npm install
npm run dev
```
Открыть http://localhost:5173

## Механики
- Дерево умений: 8 веток (дистилляция, ректификация, коммерция, огород, специи,
  фруктовый сад, пасека), кейстоуны с конфликтами, очки за продажи.
- Производство: брага -> дистилляция (мини-игра отсечения голов, 10 сек) ->
  ректификация или выдержка в бочке. Пиво, медовуха, сидр, настойки.
- Склад: 20 слотов базово, расширяется стройкой (Стеллаж +8, Сарай +20,
  Амбар +45, Логистический центр x2).
- Онлайн-магазин: детали колонны и аппарата, пивоварня, провизия, стройка.
- Авто-прогресс за оффлайн (до 7 дней), события-карточки, колебания рынка.
