# Игровые ресурсы огорода

PNG-изображения перенесены из проекта [czkm/egret-farm](https://github.com/czkm/egret-farm), автор — czkm. Автор разрешил использование PNG в проекте samosgon (по подтверждению владельца samosgon).

Сохранены оригинальные PNG без перерисовки. Большие фоновые изображения, заставки и готовые элементы интерфейса не переносились. Ресурсы предназначены для использования как отдельные игровые спрайты: земля, овощи, животные (включая варианты farm_animal2–7) и маркеры действий.

Источник: https://github.com/czkm/egret-farm/tree/master/resource/assets/mysource

 
## Дополнительные материалы

- Овощные PNG-спрайты в `crops/` перенесены из [czkm/egret-farm](https://github.com/czkm/egret-farm), папка `resource/assets/mysource/蔬菜`; исходные изображения сохранены без векторной перерисовки.
- Анимационные атласы животных и общие приёмы работы с игровыми спрайтами взяты из [toophy/sdxFarmGuiGame](https://github.com/toophy/sdxFarmGuiGame); воспроизведение кадров реализовано собственным модулем `js/farmAnimations.js`.
- Сетка грядок и базовый цикл посадки/роста/сбора дополнительно сверялись с [fariazz/html5-farming-demo](https://github.com/fariazz/html5-farming-demo); исходный код демо в проект не копировался.
